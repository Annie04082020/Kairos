# ⏳ Kairos — 私有自建專注守護與時間統計系統

> **Kairos (καιρός)** 源自古希臘語，象徵「關鍵、有質量的時刻」。  
> 專為追求極致專注、自訂彈性與 100% 隱私掌控者打造的自建版 StayFree 替代方案。

---

## 🌟 核心設計與特色 (對比傳統 StayFree)

| 特色項目 | 傳統 StayFree / 商業軟體 | 🛡️ Kairos 自建版 |
| :--- | :--- | :--- |
| **資料隱私** | 連線第三方雲端、遙測分析、有廣告疑慮 | **100% 本地 SQLite**，零外部網路連線，資料完全歸您所有 |
| **自訂分類與標籤** | 固定分類，難以依專案/工作流標記 | **多維度自由標籤** (`#coding`, `#clientA`, `#research`) 與生產力加權計算 |
| **防繞過限制機制** | 容易手動暫停或關閉提醒 | **雙層防護**：柔性呼吸提醒 + **嚴格冷卻鎖定** (自動最小化 + 全螢幕倒數遮罩) |
| **番茄鐘深度連動** | 番茄鐘與應用限制各自獨立 | **專注狀態升級**：專注階段開啟分心 App **立刻無條件封鎖**，休息階段自動放行 |
| **UI 質感與體驗** | 傳統制式介面 | **深色玻璃擬態 (Dark Glassmorphism)**、霓虹發光色系與流暢微動畫 |
| **自由擴充與匯出** | 導出受限或需付費訂閱 | **開放 REST API**、一鍵 JSON 匯出備份，隨時串接個人工作流 |

## 🚀 快速上手 (Quick Start)

### 方式 A：一鍵啟動 (推薦)
在 `D:\Kairos\` 資料夾中，直接雙擊執行：
```bat
run_kairos.bat
```
腳本將自動檢查環境，啟動背景守護進程，並在預設瀏覽器中開啟控制台：
👉 **http://127.0.0.1:5050**

### 方式 B：手動指令啟動
```powershell
# 1. 切換至專案根目錄
cd D:\Kairos

# 2. 啟動主服務
python -m kairos.main
```

## ⚙️ 核心功能詳細說明

### 1. 🖥️ 原生超輕量視窗焦點監控
- 採用 Windows 原生 `ctypes` (`GetForegroundWindow`, `GetWindowTextW`, `GetLastInputInfo`) 與 `psutil`。
- 記憶體佔用極低（約 15~25 MB），採樣間隔預設 1 秒，無卡頓、零延遲。
- 內建**滑鼠鍵盤閒置判定**（預設 3 分鐘無動作自動標記為待機，避免掛機污染統計）。

### 2. 🍅 番茄專注艙 (Focus Hub)
- 支援四種模式：
  - **🍅 專注模式** (25 分鐘)
  - **⚡ 深度心流** (50 分鐘)
  - **☕ 短休息** (5 分鐘)
  - **🌴 長休息** (15 分鐘，每完成 4 個番茄自動觸發)
- **嚴格專注防繞過 (Strict Guard)**：開啟狀態下，專注倒數進行中，若使用者切換至任何標記為負分（娛樂、社群、遊戲）之應用程式，系統將**直接強制最小化**並彈出冷卻遮罩。

### 3. 🛡️ 限制政策與防繞過 (Rules & Limits Guardian)
- **規則匹配維度**：
  - `應用程式進程` (例如: `steam.exe`, `discord.exe`, `code.exe`)
  - `視窗標題包含` (例如: `youtube`, `netflix`, `reddit`, `github`)
  - `正規表達式` (進階自訂)
- **超時處置動作**：
  - `無干預 (none)`：僅累計數據與標籤。
  - `柔性提醒 (soft_warn)`：桌面呼吸聲效溫和提醒已超額。
  - `嚴格冷卻鎖定 (strict_lock)`：直接將目標視窗最小化，並彈出 45 秒強制冷卻置頂倒數視窗。每日限定最多延長 2 次（每次 5 分鐘），杜絕無限繞過。

### 4. 🏷️ 多維度標籤與生產力權重
- 支援任意逗號分隔標籤，例如：`project_kairos, backend, research`。
- 生產力評分分為 5 個等級：
  - `+2` 深度生產力（IDE、終端機、官方文件）
  - `+1` 輔助工作（通訊通話、筆記工具）
  - `0` 中性 / 系統背景
  - `-1` 輕度分心（論壇、雜項瀏覽）
  - `-2` 重度分心 / 成癮娛樂（短影音、遊戲客戶端）
- 儀表板將自動依據加權比重計算每日 **「專注生產力指數 (Focus Score: 0~100)」**。

### 5. 🔄 Local-First 離線獨立紀錄與一鍵雙向同步 (GitHub Pages 友好)
- **三端各自獨立運作**：
  - 電腦、iPad、Android 手機平時不強制連線，即使電腦關機，iPad 與手機依然能作為獨立 PWA 運作，專注計時與離線記錄保存在裝置本機 `localStorage`。
- **一鍵聯網雙向同步**：
  - 當電腦開機、連上相同 Wi-Fi 時，只需在 iPad 或手機介面點擊頂部的 **「🔄 同步」** 按鈕。
  - 系統自動將離線累積的事件與番茄鐘批量推送至電腦 SQLite，並採用 `client_uuid` 冪等去重，多次同步絕不重複計算！
  - 支援將 `web/` 目錄直接部署至 **GitHub Pages**，出門在外隨開隨用，回家一鍵同步回電腦！

### 6. 🔒 隱私與資料管理
- 所有數據均存放於 `data/kairos.db`。
- 在儀表板「隱私與備份」分頁中，可一鍵點擊 **「下載完整 JSON 備份檔」**，方便備份或與第三方工作流串接。
