iPad / iOS 使用指南

PWA 原生全螢幕 + 捷徑自動化
  1. 加到主畫面：在 iPad Safari 開啟上方連線網址，點「分享」按鈕 ➔ 選擇「加入主畫面」，即可享受無網址列的原生 App 體驗。
  2. 防繞過自動化 (選用)：利用 iPad 內建的「捷徑 App」，設定「當開啟分心 App 時」自動向 Kairos 後端查詢是否處於專注時段。
  3. 若正在專注中，捷徑自動執行「返回主畫面」，達到在封閉系統上的強力專注防繞過！
詳細自動化動作代碼請參閱： clients/ios_shortcuts/README.md
🤖

Android 手機使用指南

Chrome PWA + 應用使用回傳
  1. 安裝 PWA：在手機 Chrome 開啟連線網址，點右上角選單 ➔ 選擇「安裝應用程式」加入手機桌面。
  2. 隨身專注控制台：在手機上一鍵啟動/重置番茄鐘、隨時查看電腦前台活躍進程。
  3. 手機 App 使用量同步 (進階)：透過 Termux 或 Tasker 執行專屬回傳腳本，自動將 Android 前台 App 使用時間累計到中央 SQLite！
腳本與說明位於： clients/android/README.md
